Add / Edit / Delete Sections

Sections are subheaders (e.g. Standing, Crouching) that can contain subsections (e.g. -10, -12). To rename one, type a new name and tap ✓ or press Enter. Use ↑↓ to reorder, 🗑/✕ to delete.

Reorder Columns

Use ↑↓ to change the order columns appear in the table. "Actions" always stays last.

Sync between devices

This app always saves on this device first, so it works with no internet. To also keep your iPad, phone and computer in step, it stores a copy in a private gist on your GitHub account and syncs whenever you're online.
✓ Sync is on for this device. Paste a new token below only if you want to replace it.
  1. Open GitHub's token page (sign in if asked).
  2. Set Expiration to "No expiration" (or a long date). Leave only gist ticked.
  3. Tap Generate token, copy it, and paste it here.
Use the same token on every device. It's stored only on this device and can only read and write your gists.

Paste a table from the wiki

On the wiki page, select the whole table including its header row (e.g. Enemy · Move · Damage · Frames), copy it, then paste below. Works for punisher tables and move lists. You'll see a preview before anything is added.
